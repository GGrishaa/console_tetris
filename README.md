# Console Tetris

Классический Тетрис для терминала, написанный на C с использованием библиотеки `ncurses`. Проект поддерживает музыку, таблицу рекордов, сид для воспроизводимости игр и приятный ASCII-интерфейс прямо в консоли.

---

## Возможности

- Цветной интерфейс на базе `ncurses`
- Фоновая музыка (через ffmpeg в отдельном процессе), с возможностью включать/выключать прямо во время игры
- Сохранение рекорда между запусками в файле `data/record.txt`
- Сид генератора случайных чисел для воспроизведения той же последовательности фигур (сохраняется в `data/seed.txt`)
- Пауза
- Экраны: старта, финиша игры, правила и пауза
- Все 7 классических фигур (I, J, L, O, S, T, Z) с вращениями и перемещениями
- Ускорение падения фигур по мере набора очков

## 📁 Структура проекта

```
tetris/
├── audio/
│   └── tetris.mp3          # фоновая музыка - можно заменить на свою
├── data/
│   ├── record.txt          # сохранённый рекорд
│   └── seed.txt            # сид для определения порядка выпадения фигур
└── src/
    ├── Makefile
    ├── main.c              # точка входа, игровой цикл
    ├── figure.c / .h       # классы, фигуры
    ├── manipulate.c / .h   # перемещения и вращения фигур
    ├── draw.c / .h         # отрисовка и инициализация поля и фигур
    ├── scenes.c / .h       # экраны
    └── music.c / .h        # управление фоновой музыкой
```

## Требования

- **Компилятор:** `gcc` с поддержкой C11
- **Библиотеки:** `ncurses`
- **Внешняя утилита:** `ffplay` из пакета ffmpeg (исключительно для воспроизведения музыки - без нее просто нет музыки, но игра возможна)

## Сборка и запуск

```bash
cd src
make
```

Доступные цели Makefile:

| Команда         | Действие                                    |
|-----------------|---------------------------------------------|
| `make`          | Собрать проект и запустить игру             |
| `make tetris`   | Только собрать бинарник `tetris`            |
| `make run`      | Запустить игру                |
| `make clean`    | Удалить объектные файлы и бинарник          |
| `make rebuild`  | `clean` + `all`                             |
| `make clang`    | Автоформатирование кода через `clang-format`|

## Управление

| Клавиша        | Действие                          |
|----------------|-----------------------------------|
| `←` `→`        | Двигать фигуру влево / вправо     |
| `↓`            | Ускорить падение фигуры           |
| `↑`            | Повернуть фигуру                  |
| `Space`        | Мгновенно уронить фигуру          |
| `p`            | Пауза                             |
| `m`            | Вкл/выкл музыку                   |
| `q`            | Выход                             |

На экране приветствия:

| Клавиша | Действие              |
|---------|-----------------------|
| `s`     | Начать игру           |
| `r`     | Показать правила      |
| `q`     | Выйти                 |

## Сид и воспроизводимость

При каждом запуске игра в конце партии показывает сид на экране. Чтобы **повторить ту же последовательность фигур**,
необходимо вписать вышедшее число в `data/seed.txt` перед запуском — игра подхватит его и сгенерирует идентичную последовательность.

---

## Очки

| Событие                    | Очки      |
|----------------------------|-----------|
| Постановка фигуры          | +10       |
| Очищена 1 линия            | +100      |
| Очищено 2 линии            | +250      |
| Очищено 3 линии            | +400      |
| Очищено 4 линии            | +600      |

Рекорд сохраняется автоматически при выходе или завершении игры.
